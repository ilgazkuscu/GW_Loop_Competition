# Data

`loop-data-ldw-2026.xlsx` was supplied for the GW LAI Data Visualization Competition by the GW Office of Sustainability. The notebook cites the original competition share link and describes 877 visits from January through October 2025.

The workbook contains visit timestamps, broad demographic categories, item counts, experience ratings, and donation status. No direct name, email, phone, address, or participant ID column was found during the repository audit.

The committed workbook is retained because it was already part of the public competition repository. Confirm the organizer's redistribution terms before copying it into another publication. Analyses should publish aggregates rather than visit-level records.
